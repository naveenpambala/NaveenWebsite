Before Starting to Learn Java, You Must Know:

  • Java is a programming language used to develop dynamic and scalable web applications.
  • Java was developed by James Gosling at Sun Microsystems in June 1991.
  • Java is a high-level, platform-independent, class-based, object-oriented programming language.
  • Java provides its own JRE (Java Runtime Environment) and API (Application Programming Interface)
  • Java is not fully object-oriented because it supports primitive data types like int, char, etc.

What is Standalone Application:

An application that runs and executes within a single PC (Personal Computer) is called a Standalone Application.
Simple Explanation: Think of apps on your computer like MS Word or Calculator - they work on your computer alone without needing the internet.

Examples:
  • MS PowerPoint
  • MS Word
  • Media Player
  • Calculator
  • Notepad

What is Web Application:

An application designed with a collection of web pages that runs in a browser through the internet is called a Web Application.
Simple Explanation: Think of websites like Facebook or Gmail - you access them through a browser (Chrome, Firefox, etc.) using the internet.

Examples:
  • www.facebook.com
  • www.amazon.com
  • www.gmail.com
  • www.netflix.com
Basically Web Applications are divided into two types:

(1) Static Web Applications

(2) Dynamic Web Applications

(1) Static Web Applications: A web application whose content does not change from one user to another user. Everyone sees the same content.

Simple Explanation: Like a digital brochure - everyone sees the same information, like a company's "About Us" page.

Examples:
  • about.html (About Us page)
  • contact.html (Contact page)
  • Company brochure websites

(2) Dynamic Web Applications: A web application whose content changes from one user to another user. Each user sees personalized content.

Simple Explanation: Like your Facebook feed - what you see is different from what your friend sees because it's personalized for you.

Examples:
  • Facebook (Your timeline is different from others)
  • Instagram (Your feed shows posts from people you follow)
  • Amazon (Shows products based on your interests)
  • Gmail (Shows your emails, not others')

What is Class?

Class is the user defined data type which consists of Variables and Methods.

What is Variable? How Many Types of Variables?
  • Variable is a name given to a particular memory location
  • Purpose of variable is to store values

Simple Explanation: Think of a variable like a labeled box where you can store things. The label is the variable name, and what you put inside is the value.

Syntax to create variable:

datatype variableName;

Example: int x = 10; (This creates a box labeled "x" that stores the number 10)

Types of Variables:

Static Variables: The variable declared inside the class and outside the method with the static keyword.

=> We access static variables using the class name

=> Static Variables automatically initialize with default values

Simple Explanation: Think of static variables like a shared whiteboard in a classroom - everyone in the class (all objects) can see and use the same whiteboard.

  • int --> 0
  • double --> 0.0
  • char --> blank
  • String --> null

Instance Variables: The variable declared inside the class and outside the method without the static keyword

=> Instance variables get memory inside every object and initialize with default values

=> We can access instance variables using object reference

Simple Explanation: Think of instance variables like personal notebooks - each student (object) has their own notebook with their own notes.

Local Variables: A variable declared inside the body of the method is called a local variable. You can use this variable only within that method. Other methods in the class aren't even aware that the variable exists.

=> A local variable cannot be defined with the "static" keyword.

Simple Explanation: Think of local variables like sticky notes you use while doing a specific task - once the task is done, you throw away the sticky note.

What is Method in Java?

=> Method is a subprogram (a block of code) which is used to perform specific tasks

Simple Explanation: Think of a method like a recipe. The recipe name is the method name, the ingredients are the parameters, and the cooking instructions are the code inside the method. When you follow the recipe (call the method), you get the final dish (result).

What are Method Parameters in Java?

=> The variables that are declared within the Method Parenthesis are called Method Parameters

=> () --> Parenthesis

=> Based on the above image, int a, int b are the method parameters (like ingredients for your recipe)

=> Method Name + Method Parenthesis = Method Signature

What is Object in Java?

=> Object is an instance of a class, which means creating an actual item from the blueprint (class) and allocating memory for instance variables

Simple Explanation: Think of a class like a blueprint for building a house. The object is the actual house built from that blueprint. You can build many houses (objects) from the same blueprint (class), and each house can have different colors, sizes, etc. (different values for variables).

Syntax of Object Creation:

ClassName referenceName = new Constructor();

Example: Car myCar = new Car(); (Creating a car object named "myCar")

What is OOP?

=> OOP stands for Object-Oriented Programming, which is used to write programs by using classes and objects.

Simple Explanation: OOP is like organizing your things into categories. For example, all your books go on a bookshelf, all your clothes go in a closet. Similarly, OOP organizes code into classes (categories) and objects (actual items).

Advantages of OOP:
  • Modularity: Code is organized in separate units (like keeping different subjects in different notebooks)
  • Reusability: You can use the same code again and again (like using the same recipe to bake multiple cakes)
  • Scalability and Maintainability: Easy to add new features and fix problems (like adding new rooms to a house)
  • Security: Hide important details from users (like hiding your password)

Main Concepts of Object-Oriented Programming:-

  1. Abstraction
  2. Encapsulation
  3. Inheritance
  4. Polymorphism

Abstraction :

Abstraction is the process of hiding the implementation details and showing only the necessary information to the user.

Real-World Example:
  • Think of a car:
    • You only need to know how to drive it (steering, brakes, accelerator).
    • You don’t need to know how the engine, transmission, or braking system works internally.
Example Program:
          
            abstract class Vehicle {
              abstract void start();  // Abstract method (no implementation)
          }
          
          class Car extends Vehicle {
              @Override
              void start() {
                  System.out.println("Car starts with a key or button.");
              }
          }
          
          public class Main {
              public static void main(String[] args) {
                  Vehicle myCar = new Car();
                  myCar.start();  // Output: Car starts with a key or button.
              }
          }
  • Explanation:
    • Vehicle is an abstract class, defining the concept of starting a vehicle but hiding the details.
    • Car provides the actual implementation
    • The user only interacts with the start() method without worrying about how it works internally.

Encapsulation:

Encapsulation is the process of wrapping data (variables) and code (methods) together into a single unit called a class. It also means hiding the internal details and allowing access only through specific methods.

Real-World Example:
  • Think of a medicine capsule:
    • The medicine powder (data) is wrapped inside a capsule (class).
    • You don't need to see or touch the powder directly; you just swallow the capsule.
    • The capsule protects the medicine and controls how you take it.
  • Another Example - ATM Machine:
    • You can withdraw money using buttons (public methods).
    • You can't see or access the internal cash storage or mechanisms (private data).
Example Program:
          
            class BankAccount {
                private double balance;  // Private variable (hidden from outside)
            
                // Public method to deposit money
                public void deposit(double amount) {
                    if (amount > 0) {
                        balance = balance + amount;
                        System.out.println("Deposited: " + amount);
                    }
                }
            
                // Public method to get balance
                public double getBalance() {
                    return balance;
                }
            }
            
            public class Main {
                public static void main(String[] args) {
                    BankAccount myAccount = new BankAccount();
                    myAccount.deposit(1000);
                    System.out.println("Balance: " + myAccount.getBalance());
                    // We cannot directly access myAccount.balance (it's private)
                }
            }
  • Explanation:
    • The balance variable is private, so no one can directly access or change it.
    • We can only use deposit() and getBalance() methods to interact with the balance.
    • This protects the data from unauthorized access and ensures it's modified correctly.

Inheritance:

Inheritance is a mechanism where a new class (child class) can acquire the properties and methods of an existing class (parent class). This promotes code reusability.

Real-World Example:
  • Think of family relationships:
    • Children inherit characteristics from their parents (like eye color, height, etc.).
    • Similarly, a child class inherits features from its parent class.
  • Another Example - Vehicle Family:
    • All vehicles have common features: engine, wheels, brakes.
    • Car, Bus, and Bike are specific types of vehicles that inherit these common features.
    • Each can also have its own unique features (Car has AC, Bike has helmet storage).
Example Program:
          
            // Parent class
            class Animal {
                String name;
            
                public void eat() {
                    System.out.println(name + " is eating");
                }
            
                public void sleep() {
                    System.out.println(name + " is sleeping");
                }
            }
            
            // Child class inherits from Animal
            class Dog extends Animal {
                public void bark() {
                    System.out.println(name + " is barking: Woof! Woof!");
                }
            }
            
            // Another child class
            class Cat extends Animal {
                public void meow() {
                    System.out.println(name + " is meowing: Meow! Meow!");
                }
            }
            
            public class Main {
                public static void main(String[] args) {
                    Dog myDog = new Dog();
                    myDog.name = "Buddy";
                    myDog.eat();    // Inherited from Animal
                    myDog.sleep();  // Inherited from Animal
                    myDog.bark();   // Dog's own method
            
                    Cat myCat = new Cat();
                    myCat.name = "Whiskers";
                    myCat.eat();    // Inherited from Animal
                    myCat.meow();   // Cat's own method
                }
            }
  • Explanation:
    • Animal is the parent class with common features (eat, sleep).
    • Dog and Cat are child classes that inherit these features.
    • Each child class can also have its own unique methods (bark for Dog, meow for Cat).
    • This saves us from writing eat() and sleep() methods again for Dog and Cat.

Polymorphism:

Polymorphism means "many forms." It allows one thing to take multiple forms. In Java, it means you can use the same method name to perform different actions.

Real-World Example:
  • Think of a person:
    • The same person can be a father at home, an employee at work, and a friend at a party.
    • Same person, different roles/behaviors in different situations.
  • Another Example - The word "Bank":
    • River Bank (side of a river)
    • Money Bank (financial institution)
    • Blood Bank (stores blood)
    • Same word, different meanings based on context.
Example Program:
          
            class Shape {
                public void draw() {
                    System.out.println("Drawing a shape");
                }
            }
            
            class Circle extends Shape {
                @Override
                public void draw() {
                    System.out.println("Drawing a Circle ⭕");
                }
            }
            
            class Square extends Shape {
                @Override
                public void draw() {
                    System.out.println("Drawing a Square ⬜");
                }
            }
            
            class Triangle extends Shape {
                @Override
                public void draw() {
                    System.out.println("Drawing a Triangle 🔺");
                }
            }
            
            public class Main {
                public static void main(String[] args) {
                    Shape myShape;  // Parent class reference
            
                    myShape = new Circle();
                    myShape.draw();  // Calls Circle's draw()
            
                    myShape = new Square();
                    myShape.draw();  // Calls Square's draw()
            
                    myShape = new Triangle();
                    myShape.draw();  // Calls Triangle's draw()
                }
            }
  • Explanation:
    • The draw() method exists in all classes, but it behaves differently in each.
    • We use the same method name draw(), but it performs different actions based on the object type.
    • This is like saying "draw" to different artists - each will draw in their own style.
